# Travel Planner

A starter workspace with an ASP.NET Core backend and React frontend.

## Backend

- Project: `TravelPlanner/TravelPlanner.csproj`
- Targets .NET 8.0
- Sample API: `WeatherForecast`

## Frontend

- Client app lives in `app`
- Uses React and `react-scripts`
- Proxy configured to `http://localhost:5223`

## Setup

1. Install .NET SDK 8.0 or later.
2. Install Node.js 18 or later.
3. From `app`, run `npm install`.
4. Start the backend from `TravelPlanner` with `dotnet run`.
5. Start the frontend from `app` with `npm start`.

> Note: This workspace was scaffolded successfully, but the current environment does not have a .NET SDK or Node.js installed. Install both runtimes before building or running the app.
